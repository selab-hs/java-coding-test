# 개요

* Union : 서로 다른 두 개의 집합을 하나의 집합으로 병합하는 연산을 말한다.
    * 이 자료구조에서는 상호 배타적 집합만을 다루무로 Union 연산은 합집합 연산과 같다
* Find : 하나인 원소가 어떤 집합에 속해있는지 판단한다

크루스칼 알고리즘과 프림 알고리즘을 알기 위해서 유니온 파인드 알고리즘을 알아야 한다

<br>

# 설명

* 1~4 번 학생이 친구이다
* 5~6번 학생이 친구이다
* 두 그룹은 공통 원소가 없기 때문에 서로 소집합 즉 Disjoin-set이라고 할 수 있다
* **이것을 판별하는 알고리즘이 Union Find 알고리즘이다**
