# 계단 오르기
* 시간 : 20분
* 시간 초과로 답지 확인

### 오답 코드
```java
import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

    public static void main(String[] args) throws IOException {
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        int[] step = new int[n];
        int[][] dp = new int[n][2];

        for (int i = 0; i < n; i++) {
            step[i] = Integer.parseInt(new StringTokenizer(br.readLine()).nextToken());
        }

        if (n < 2) {
            System.out.println(step[0] + step[1]);
        } else {
            dp[0] = new int[]{step[0], 0};
            dp[1] = new int[]{step[1] + step[0], 1};
            for (int i = 2; i < n; i++) {
                if (dp[i - 2][0] < dp[i - 1][0] && dp[i - 1][1] < 1) {    //1 계단 오름
                    dp[i] = new int[]{dp[i - 1][0] + step[i], dp[i - 1][1] + 1};
                } else { //2 계단 오름
                    dp[i] = new int[]{dp[i - 2][0]+ step[i], 0};
                }
            }
            System.out.println(dp[n-1][0]);
        }
    }
}
```

### 정답 코드
```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.io.IOException;
 
public class Main {
 
	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
 
		int N = Integer.parseInt(br.readLine());
 
		int[] DP = new int[N + 1];
		int[] arr = new int[N + 1];
 
 
		for (int i = 1; i <= N; i++) {
			arr[i] = Integer.parseInt(br.readLine());
		}
 
		// index = 0 은 시작점이다.
		DP[1] = arr[1];
		
		// N 이 1이 입력될 수도 있기 때문에 예외처리를 해줄 필요가 있다.
		if (N >= 2) {
			DP[2] = arr[1] + arr[2];
		}
 
		for (int i = 3; i <= N; i++) {
			DP[i] = Math.max(DP[i - 2] , DP[i - 3] + arr[i - 1]) + arr[i];
		}
 
		System.out.println(DP[N]);
	}
}
```
* 반복문을 사용한 Bottom-Up 방식
* 재귀를 사용한다면 Top-Down 방식으로 풀 수 있다
* `i - 3`을 잘못 사용하면 배열 범위를 벗어난다

```java
for (int i = 3; i <= N; i++) {
	DP[i] = Math.max(DP[i - 2] , DP[i - 3] + arr[i - 1]) + arr[i];
}
```
위 코드로 푸는데 연속하지 않는 것을 걸러내기 위해서 `i-3` & `i-1` vs `i-2` 로 비교한다
