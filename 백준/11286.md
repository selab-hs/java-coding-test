# 절댓값 힙
* 시간 : 10분
```java
import java.io.*;
import java.util.*;

public class Main {
    static BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

    public static void main(String[] args) throws IOException {
        StringTokenizer st = new StringTokenizer(br.readLine());
        int n = Integer.parseInt(st.nextToken());
        PriorityQueue<Integer> pq = new PriorityQueue<>(new AbsoluteValueComparator());

        for (int i = 0; i < n; i++) {
            st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());

            if (a == 0) {
                if (pq.isEmpty()) {
                    System.out.println(0);
                } else {
                    System.out.println(pq.poll());
                }
            } else {
                pq.add(a);
            }
        }
    }

    static class AbsoluteValueComparator implements Comparator<Integer> {
        @Override
        public int compare(Integer o1, Integer o2) {
            int i = Math.abs(o1) - Math.abs(o2);
            if (i > 0) return i;
            else if (i < 0) return -1;
            else return o1 - o2;
        }
    }
}
```

# 배운 것
비교해야 한다면 Comparator 클래스를 구현하는 것도 좋은 방법이다.
